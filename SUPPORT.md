### Questions

Before opening an issue:

1. Search [existing issues](https://github.com/windsornguyen/microvm/issues)
2. Check if you're on the latest version
3. Verify your entitlements are correct (`codesign -d --entitlements - $(which microvm)`)

### Bugs

[Open an issue](https://github.com/windsornguyen/microvm/issues/new).

Include:

- macOS version (`sw_vers`)
- Hardware (`uname -m`)
- microvm version (`microvm version`)
- Steps to reproduce
- Expected vs actual behavior

### Security Issues

**Do NOT open public issues for security vulnerabilities.**

[Report privately via GitHub](https://github.com/windsornguyen/microvm/security/advisories/new). See [SECURITY.md](SECURITY.md).
